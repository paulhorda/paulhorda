# Paul Horda

SOC / Blue Team

My focus is authentication logs, alert triage and detection rules. My earlier projects are in Android and Kotlin.

## Projects

**[Authentication log analysis](https://github.com/paulhorda/soc-log-analysis)**

SQLite queries for failed logins, attempts against multiple accounts and successful logins after repeated failures. Includes the input logs, query results and notes on what needs further investigation.

**[SOC alert triage](https://github.com/paulhorda/soc-alert-triage-lab)**

A Python detector for the same events. Three rules, alert deduplication, evidence timelines and a worked case. Includes a stale-credential false positive and a slow sequence the rules miss.

Both use generated lab data. They are two ways of examining the same sample: SQL for investigation and Python for alerting.
